# Ashwini Amruttulya — Tea Shop Website

A concept website built for **Ashwini Amruttulya**, a real tea shop on Drogapara Road, Raigarh, Chhattisgarh — built independently, not yet a commissioned client project.

## About

Vanilla HTML/CSS/JS single-page site featuring a warm gold/dark visual theme, animated scroll reveals, a services/menu section, gallery, and customer testimonials pulled from the shop's real reviews.

## Live Demo

[View Live](https://lucasocyenic-bit.github.io/ashwini-amruttulya/) *(via GitHub Pages)*

## Built With

- HTML5 / CSS3 / Vanilla JS
- Google Fonts (Playfair Display, Poppins)
- Intersection Observer API for scroll animations

## Status

Concept build — created as a portfolio piece and outreach sample for the business.
